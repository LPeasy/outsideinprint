# Bob reading Worker

This service powers the small reading assistant on Outside In Print. It uses
`gpt-6-luna` through Responses, with standard service tier, `store:false`, no
reasoning, strict catalog-ID output, and at most 500 output tokens. Browser
collection browsing makes no requests to this service or OpenAI.

The owner approved production activation on October 14, 2026. The configured
endpoint is `https://oip-bob-reading.red-snow-678d.workers.dev`; version preview
URLs remain disabled. Credentials are server secret bindings and are never
tracked. CI runs tests only. Neither `npm test` nor the bundle check deploys a
Worker. Subsequent publication follows the site's checked PR process.

## Components

- `src/recommender.js`, `preferences.js`, `search.js`, `transport.js`: port of the
  tested local preview, including bounded memory, metadata retrieval and filters.
- `src/index.js`: bounded JSON ingress, exact-origin CORS, canonical catalog
  fetch, safe error responses and the production kill switch.
- `src/budget.js`: one SQLite Durable Object coordinates admission, concurrent
  requests and daily/monthly reservations across every Worker isolate.
- `/companion-bob/catalog.json`: generated by Hugo from published site content,
  with one version for cards, collection membership and API recommendations.
  The Worker caches it for five minutes. A client version mismatch forces one
  refresh, then returns `catalog_changed` without calling OpenAI if necessary.

## Limits and accounting

The proposed initial OpenAI allowance is **$0.50 per UTC day and $5 per UTC
calendar month**. These are the owner-approved application limits; changing them
does not purchase or change a Cloudflare hosting plan.
Both must have room before dispatch. A missing budget binding, failed ledger,
missing secret or unreadable catalog fails closed. See
[the cost plan](../../docs/bob-reading-cost-plan.md) for measured usage and
separate Cloudflare hosting costs.

Each call reserves an upper estimate using every UTF-8 byte in the serialized
OpenAI request plus 4,096 framing tokens, at $0.125 per million input tokens and
$0.50 per million output tokens. The input rate conservatively includes the
cache-write premium; cache discounts are ignored. Requests over 64 KiB are
rejected before dispatch. Only valid reported token usage releases excess
allowance. Unknown, failed or interrupted outcomes keep the full reservation;
the browser never automatically retries. Price changes, other applications
using the key, and Cloudflare charges are outside this application ledger.
Recheck the dated rate assumptions before activation; configure a dedicated
OpenAI project's enforced spending limit as secondary protection where available.

Admission allows six requests/minute and 40/day per hashed visitor address,
60/minute globally, and four active model reservations. Unknown completions hold
their slot for the remainder of a 60-second lease. An IP address is HMAC-hashed
with a server secret and UTC date; raw addresses and prompts are never stored
in this ledger. Shared networks share a visitor limit. Origin restrictions are
browser access controls, not authentication; direct scripted callers are still
subject to the same durable budget. Limits may be adjusted after observed use.

Chat memory is page-session context, sent with each request; there is no chat
history database. `store:false` does not promise zero OpenAI retention. Platform
observability starts disabled to avoid automatic request logging; application
diagnostics contain fixed event/error codes only. Use platform aggregate
request/error metrics, and review any future log configuration before enabling it.

## Local verification

Use the repository's pinned Node wrapper. Dependency installation is needed to
exercise workerd, not an extra generic OIP publication gate:

```powershell
& ..\..\tools\bin\generated\npm.cmd ci --ignore-scripts --no-audit --no-fund
& ..\..\tools\bin\generated\node.cmd --test test/*.test.mjs
& ..\..\tools\bin\generated\node.cmd node_modules/wrangler/bin/wrangler.js deploy --dry-run --outdir .wrangler/dry-run
```

Tests make no paid calls. Runtime tests intercept every outbound request and
exercise the Worker and SQLite Durable Object inside workerd. The dependency
lock and compatibility date are pinned. No Cloudflare login is needed for these
checks.

The stable Miniflare 4 test dependency has scoped overrides for `sharp` 0.35.5
and `undici` 7.29.1, which contain fixes for the advisories affecting its original
transitive pins. Wrangler's bundled Miniflare already uses those fixed versions.
Review these overrides when updating Miniflare; Dependabot checks this separate
package weekly. None of these development packages is imported by the deployed
recommendation code.

For a live local review, serve the site's local override at `127.0.0.1:8769`
and run `tools/local-review.mjs --allow-live --env-file <approved-env-file>` with
the pinned Node wrapper. That helper reads the already-approved preview key
directly into memory, listens on loopback port 8787, and never writes the key to
this worktree. Each submitted request can incur OpenAI usage. The helper does
not use Cloudflare remote development or deploy anything.

## Production deployment

1. Review the exact frontend, catalog, Worker, runtime export and CI changes.
   Preserve the Idle Times runtime's source changes and provenance as well.
2. Confirm the Cloudflare account/plan, endpoint hostname, usage allowance and
   OpenAI project. The configured existing account is
   `2ca1eb7fa751f89602fd324e26dc16c7`. Using its Workers endpoint does not require
   moving the site's DNS zone. Provider billing settings are separate from the
   application's daily/monthly caps.
3. Provision the Worker and its SQLite binding, retaining the stable budget
   object name. Supply `OPENAI_API_KEY` and a random 32+ character
   `IP_HASH_SECRET` through server secret bindings, never tracked vars, browser
   bundles, screenshots or command arguments. Secret upload/deployment are
   separate authorized operations; the local review helper does neither.
4. Keep chat closed until the generated public catalog exists and the real
   origin/CORS/secret bindings have been checked. Configure the selected HTTPS
   endpoint in `params.bob_reading.api_base` and enable chat only after the
   coordinated release passes review. Static collections remain usable when
   chat is off or its allowance is exhausted.
5. Follow the current OIP reviewed PR, `release-ready`, authorized auto-merge,
   fresh Pages build and exact commit/time verification flow. Separately verify
   the deployed Worker's version, bindings, kill switch and one bounded live
   request. Local workerd checks do not establish deployed Cloudflare behavior.

Do not delete/recreate the budget namespace or rename its singleton to reset
limits. That would discard its accounting. To stop paid use immediately, set
`CHAT_ENABLED=false`; do not delete the catalog or collection UI.
